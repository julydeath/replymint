02 · Overlay design system

Glass, not toasts.

Every transient state that used to be a system toast becomes a designed, in-overlay moment. The overlay never contains a text input — a hard constraint of the accessibility architecture — so every state is glanceable and tap-light.

Bubble · idle
54dp orb, mint radial gradient, soft breathing glow. Appears only when an editable field is on screen; drag-dockable to either edge.
Menu · expanded
Dark glass, 20dp radius, blur + inner highlight. Pops from the bubble's corner; Undo row appears only when a draft snapshot exists.
Voice · listening
Listening…
Tell him Saturday works, and ask about parking
Live waveform + streaming transcript replace the old bare panel. Deliberately not dismissable by an outside tap while recording.
Writing · in progress
Writing…
Shimmering glass pill floats above the composer while the draft streams in — replaces the "Writing…" system toast.
Success + Undo
Draft ready — review & send
Success confirms without stealing focus; the Undo chip lingers for a few seconds, then retreats into the menu.
Errors & limits
Tap the reply box, then try again
Daily limit reached — resets at midnight
Errors use the same pill language with a coral accent — calm, specific, and never a system toast.
